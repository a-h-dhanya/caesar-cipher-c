# Caesar Cipher in C

A simple menu-driven Caesar Cipher program written in C.

## Features

- Encrypt a message using a Caesar shift
- Decrypt an encrypted message
- Menu-driven interface
- Handles alphabetic characters

## How It Works

The Caesar Cipher is a substitution cipher where each letter
is shifted by a fixed number of positions in the alphabet.

For example, with a shift of 3:

A → D
B → E
C → F

## Concepts Used

- C programming
- Functions
- Loops
- Conditional statements
- Strings
- Character manipulation
